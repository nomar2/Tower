# Contributing

Pull requests are welcome.

1. Fork and clone the repository.
2. Create `local.properties` (see `local.properties.example`).
3. Make your change and build it:

   ```
   ./gradlew :Android:assembleDevDebug
   ```

4. Push to your fork and open a pull request.

Please keep changes focused and match the surrounding code style. This project
is licensed under the GNU GPL v3; contributions are accepted under the same
license.
